# Musme developer assets

Use `brand_tokens.css` directly or map `brand_tokens.json` into the consuming design system.

The approved primary color is `#6BEFBC`. The 300 and 700 values are functional extensions for hover, contrast, and hierarchy. Keep primary actions mint with dark mint-ink text. Use Mint Dark for mint-colored text on light surfaces.

Website mark: `/public/images/musme-logo-mark.png`

Next.js file-based icons are installed at `/app/icon.png`, `/app/apple-icon.png`, and `/app/favicon.ico`.
