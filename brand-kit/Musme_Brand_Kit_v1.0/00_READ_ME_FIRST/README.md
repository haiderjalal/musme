# Musme Brand Kit v1.0

Status: local web brand kit based on the user-supplied approved raster logo.

## Approved identity

- Canonical artwork: `01_MASTER_LOGOS/PNG/Musme_Logo_Approved_Raster_Master.png`
- Primary brand color: Musme Mint, `#6BEFBC`, RGB `107, 239, 188`
- Primary typography: Geist, with Arial as the broad system fallback
- Technical typography: Geist Mono, with a generic monospace fallback

The supplied logo is raster artwork. This kit does not claim to contain a true SVG or vector PDF master. Its geometry has not been redesigned or retyped.

## Usage

- Use the transparent mark on charcoal, white, or quiet neutral backgrounds.
- Preserve clear space around the mark equal to at least one quarter of its visible height.
- Do not recolor, outline, distort, rotate, add glow, or place the mark over visually busy imagery.
- Use Musme Mint for primary actions and focus states. Use the darker mint companion for small text on light backgrounds.
